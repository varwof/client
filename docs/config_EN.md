# varwof-cli Configuration Reference

## Config Struct

```json
{
  "server": "https://pki-core:4433",
  "ca_cert": "/etc/pki/ca.pem",
  "client_cert": "/etc/pki/admin.pem",
  "client_key": "/etc/pki/admin.key",
  "key_password": "optional-password",
  "token": "optional-bearer-token"
}
```

| Field | Type | Required | Description |
|------|------|------|------|
| `server` | string | **Yes** | core service URL |
| `ca_cert` | string | **Yes** for mTLS | CA certificate path (for verifying the server) |
| `client_cert` | string | **Yes** for mTLS | Client certificate path (mTLS identity) |
| `client_key` | string | **Yes** for mTLS | Client private key path |
| `key_password` | string | No | Private key password (applies to both plaintext and encrypted private keys) |
| `token` | string | **Yes** for token mode | Bearer token; used automatically when `server` is `http://`, skipping mTLS |

## Plaintext + Token Mode (Smoke/Dev Environments)

When `server` starts with `http://`, varwof-cli skips mTLS verification and uses `Authorization: Bearer <token>` instead:

```json
{
  "server": "http://127.0.0.1:8445",
  "token": "f530f9ffd0c279f8d8fe139260c9b8ef...",
  "ca_cert": "",
  "client_cert": "",
  "client_key": ""
}
```

## Encrypted Private Keys

Supports the PKCS#8 EncryptedPrivateKeyInfo format (PBES2 + PBKDF2-SHA256 + AES-256-CBC).

Compatible with encrypted private keys generated by `openssl pkey -aes-256-cbc -pass pass:xxx`.

## Multiple Identity Configurations

Use different config files for different permissions:

```bash
# Admin operations
varwof-cli admin.json issue --cn "new-cert"

# Auditor operations
varwof-cli auditor.json list --status revoked

# Ops operations
varwof-cli ops.json renew --ca issuing --serial ABCD1234
```

## aic batch Config File (batch.json)

A separate config file used by `aic batch` / `aic list` (compatible with the merged pki-aic-tool `config.json`):

```json
{
  "ca": "Issuing CA",
  "out_dir": "./certs",
  "users": [
    { "name": "zhangsan", "ou": "gateway:ops", "caps": ["mysql:SELECT:*", "mysql:INSERT:*"] }
  ],
  "agents": [
    { "user": "zhangsan", "agent": "agent-zs-001", "caps": ["mysql:SELECT:*", "mysql:INSERT:*"] }
  ]
}
```

| Field | Type | Description |
|------|------|------|
| `ca` | string \| [string] | Issuing CA (shared by users and agents) |
| `out_dir` | string | Output directory (certificates/private keys) |
| `users[].name` | string | Username, used as the user certificate CN |
| `users[].ou` | string | Optional OU (`gateway:<role>` required for agent-proxy) |
| `users[].caps` | [string] \| string | User certificate capabilities |
| `agents[].user` | string | Associated username |
| `agents[].agent` | string | agent_id |
| `agents[].caps` | [string] \| string | AIC capabilities |

## Environment Variables

| Variable | Description |
|------|------|
| `PKI_KEY_PASSWORD` | Global private key password (per-config `key_password` takes precedence) |
